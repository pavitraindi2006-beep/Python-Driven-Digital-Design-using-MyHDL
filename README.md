# Python-Driven-Digital-Design-using-MyHDL
Designed a Booth Multiplier and MAC unit using MyHDL (Python), applying arithmetic optimization and datapath concepts. Converted the design to Verilog, synthesized it using Xilinx Vivado, and deployed the bitstream on PYNQ-Z2 for hardware verification via Jupyter Notebook. Explored ML-based image processing acceleration.
